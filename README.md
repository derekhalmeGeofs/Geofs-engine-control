# GeoFS Universal Engine Control

A userscript for GeoFS that adds individual engine shutdown and restart controls to compatible aircraft.

## Features

- Automatically detects the aircraft's engine count
- Generates individual engine controls
- Start All Engines
- Shutdown All Engines
- Aircraft detection
- Hide and reopen control panel

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/)
2. Open the engine control userscript file in this repository
3. Click **Raw**
4. Tampermonkey should prompt you to install the script
5. Click **Install**
6. Reload GeoFS

## Compatibility

Designed for GeoFS aircraft that expose compatible engine objects. Engine control compatibility may vary between aircraft.

## Controls

- **Shutdown** — disables the selected engine's thrust
- **Start** — restores the engine's original thrust configuration
- **Start All Engines** — restores all engines
- **Shutdown All Engines** — disables all engines
